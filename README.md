# מד קליטה (Signal Meter)

אפליקציית אנדרואיד לאבחון עוצמת קליטה סלולרית בזמן אמת - **לא** "משפרת"
קליטה (זה בלתי אפשרי בתוכנה), אלא נותנת מדידה מדויקת (dBm/ASU/רמה) כדי
להשוות בין שני מכשירים זהים באותו מקום.

נבנתה לפי מדריך התאימות ל-Android 4.4 ומכשירי מקשים - קוד אחד, `minSdk 19`
קבוע, `targetSdk 34` עדכני, כל קריאת API חדשה עטופה בבדיקת גרסה.

## מה מוצג

- עוצמת אות ב-dBm (מדויק מ-API 29, מחושב מ-ASU בגרסאות ישנות יותר)
- ASU ורמה (0-4)
- סוג רשת (2G/3G/4G/5G) ושם מפעיל
- מינימום/ממוצע/מקסימום ומספר מדידות מאז פתיחת המסך (או מאז איפוס)

## הרשאות

הרשאה יחידה: `READ_PHONE_STATE` (נדרשת כדי לקרוא עוצמת אות וסוג רשת).
מבוקשת בזמן ריצה מ-API 23 ומעלה; במכשירים ישנים יותר מאושרת בהתקנה.

## בנייה

```bash
./gradlew assembleDebug
```

ה-APK הסופי: `app/build/outputs/apk/debug/SignalMeter-1.0-debug.apk`

שני pipelines מקבילים (`.github/workflows/build.yml` ו-`.gitlab-ci.yml`)
בונים APK debug אוטומטית בכל push, עם `versionCode` מתעדכן לפי מספר הריצה.

## איך להשוות בין שני המכשירים

1. להתקין את אותו APK בשני המכשירים.
2. לעמוד באותו מקום בדיוק (הפרש של מטר יכול לשנות משמעותית).
3. ללחוץ "אפס מדידה" בשניהם באותו רגע ולחכות כ-30-60 שניות לצבירת מדגם.
4. להשוות את שורת המינימום/ממוצע/מקסימום - הבדל עקבי של 10+ dBm מצביע
   על בעיית חומרה/אנטנה אמיתית במכשיר החלש יותר, לא על דמיון.
